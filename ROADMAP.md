# ROADMAP — пошаговый план для Claude Code

## Как работать

1. Открывайте Claude Code в папке `lingua`. Каждую новую сессию начинайте с фразы:
   ```
   Прочитай CLAUDE.md и ROADMAP.md. Скажи, на каком мы шаге и что осталось сделать.
   ```
2. Копируйте промпт текущего шага **целиком**. Один шаг за раз.
3. Когда Claude Code спрашивает разрешение на команду, прочитайте, что он делает, и подтвердите.
4. После каждой части проверьте в браузере по списку «Готово, когда». Не переходите дальше, пока всё не работает.
5. Шаг большой? Разрешено и нормально работать над ним несколько сессий.

Статус: `[x]` сделано, `[ ]` не начато, `[~]` в работе. Claude Code обновляет его сам.

## [x] Шаг 3. Placement test и English Profile

```
Шаг 3 из ROADMAP. Сделай вступительный тест по правилам «Тесты и оценки» и «Продуктовые решения» в CLAUDE.md.

- Попытка теста: старт, получение следующего вопроса, ответ, завершение; можно продолжить прерванную попытку.
- Блоки Grammar, Vocabulary, Reading, Listening — полуадаптивная лестница, автопроверка на сервере.
- Speaking: 2–3 вопроса, запись голоса в браузере (только при согласии VOICE_RECORDING), загрузка в S3; итог по speaking выставляет куратор по рубрике, до этого профиль показывает «ожидает оценки».
- Расчёт баллов 0–100, уровней CEFR, overall, сильного и слабого навыка; история снимков.
- Web: экран теста с прогрессом по блокам, таймером и аудиоплеером; страница результата с English Profile, как на лендинге.
- Для теста без регистрации (с лендинга): результат показать сразу, для сохранения — предложить зарегистрироваться.

Покажи на примере, как из ответов получается уровень. Добавь проверки в smoke-тест.
```

**Готово, когда:** вы проходите тест целиком, в том числе записываете голос, и видите профиль по 5 навыкам. Отвечая специально плохо, получаете уровень ниже. В инструментах разработчика браузера (вкладка Network) не видно правильных ответов.

## [ ] Шаг 5. Куратор и домашние задания

```
Шаг 5 из ROADMAP.

- Домашние задания: из урока и назначенные куратором; срок; статусы (назначено, сдано, проверено, возвращено на доработку).
- Самостоятельная работа: для заданий с флагом контроля фиксировать сигналы браузера (уход со вкладки, выход из полноэкранного режима, вставка текста, простой) — показывать куратору как отметки, без автоматических выводов «списал».
- Кабинет куратора: список учеников с фильтрами («не занимался N дней», «низкий результат», «есть непроверенные»), карточка ученика (профиль, история, ошибки, записи speaking, ДЗ), очередь проверки, оценка по рубрике и комментарий, возврат на доработку, назначение задания, редактирование плана ученика.
- Оценка speaking куратором обновляет навык Speaking в профиле.
- Все просмотры записей голоса пишутся в аудит.
```

**Готово, когда:** ученик сдаёт ДЗ с записью голоса → куратор видит его в очереди, слушает, ставит оценку и комментарий → ученик видит результат, профиль обновился. Другой куратор этого ученика не видит.

## Полезные промпты на любой случай

**Что-то сломалось**
```
Вот ошибка: [вставьте текст или скриншот]. Найди причину, объясни простыми словами и исправь. Проверь, что остальное работает.
```

**Не понимаю, что произошло**
```
Объясни как новичку, что ты сейчас сделал, какие файлы изменил и зачем.
```

**Хочу откатить последние изменения**
```
Последние изменения всё сломали. Покажи последние коммиты и верни проект к последнему рабочему состоянию.
```

**Проверка перед переходом к следующему шагу**
```
Проверь текущий шаг: всё ли из промпта сделано, проходят ли тесты, соблюдены ли правила CLAUDE.md. Составь список недоделок.
```

**Изменить продуктовое решение**
```
Хочу изменить правило: [опишите]. Сначала скажи, что это затронет, потом внеси изменение и обнови CLAUDE.md.
```
